# ReadSharp: Tell vs Feel

A Flagsmith A/B experiment on the free reading speed test at [readsharp.app](https://readsharp.app), built for the Toggle Wars hackathon (Track 01, Test Something Real).

- The pre-registration (hypothesis, metrics, decision rule) is in [EXPERIMENT.md](EXPERIMENT.md).
- Setup steps, results and the demo video will be added here as the experiment runs.

No keys are stored in this repository. Scripts read them from environment variables.
